Live Chrome Surface: open a website in Chrome, then click the Companion toolbar icon on that active tab and choose “Stream this tab to Nolane”. The actual Chrome tab is captured as a local video stream; mouse and keyboard input from the canvas are sent back to that tab. No frame relay or server is used.

Permission warning: version 0.2.13 requires Chrome’s debugger and tab-capture permissions. Chrome warns that debugger can access the page debugger backend and read/change data on all websites. The implementation uses fixed input commands and viewport metrics, but the permission itself is broad. Install only if you trust the source code.

Native Windows browser surfaces: the standard GitHub Pages site cannot create real embedded browser controls inside Chrome. For direct in-canvas website interaction, download and run the Windows host below. It places real WebView2 browsers over ordinary website cards. The host keeps its own login profile and does not copy Chrome cookies; cards linked to Chrome tabs continue using the original Chrome session.
